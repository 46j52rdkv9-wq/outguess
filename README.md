# Outguess

A penalty game where two neural networks learn to read your swipe.

**Play:** https://46j52rdkv9-wq.github.io/outguess/

## Install on your phone

- **iPhone:** open the link in Safari, tap Share, then **Add to Home Screen**.
- **Android:** open the link in Chrome, tap the menu (⋮), then **Install app** (or **Add to Home screen**).

It runs full screen, works offline, and saves on your phone. New versions install themselves the next time you open the app and are on the main menu.

## Your data

Everything is stored on your phone. Use **Settings → Backup → Save** to keep a copy, and **Restore** to load it on another phone.

## Files

- `index.html` — the whole game (both brains and the physics engine run in the page)
- `sw.js` — keeps the game available offline and handles updates
- `manifest.webmanifest`, icons — what makes it installable
